本人大一期间完成的机器学习与深度学习、Python编程、Web全栈开发项目，涵盖算法建模、爬虫自动化、前后端开发等小项目。

## 核心技能模块
### 1. 机器学习与深度学习（machine-learning/）
- 技术栈：Python、Pandas、numpy、Scikit-learn、Matplotlib、Tensorflow、seaborn、jupyter
- 核心内容：线性回归、多元线性回归、逻辑回归、决策树、随机森林、浅层神经网络、卷积神经网络
- 日记: 2026年1月份开始学习了机器学习与深度学习的几个算法，刚开始基本调TensorFlow现成的库去使用,后面也逐步了解其中原理,最为深刻的应该是神经网络前向传播,反向传播,梯度下降,以及CNN的卷积、池化原理

### 2. Python编程（python-projects/）
- 技术栈:requests,BeautifulSoup,jieba,pandas,numpy,Matplotlib、Pyecharts、jupyter
- 爬虫：爬取新闻、壁纸、招聘数据并导出Excel、百度引擎爬取关键字图片系统
- 自动化：浏览器自动化、Excel表格生成
- 数据分析：电商客户分析、天气预报查询系统、奶茶店数据分析、酒店数据分析、抖音热门商品数据分析

### 3. Web全栈开发（web-development/）
- 技术栈:MySQL、Flask、HTML、CSS
- 后端：使用Flask搭建接口服务，封装MySQL数据库操作

- 前端基础：作业提交检查功能、UI组件（密码框）、创客企业网站页面开发
